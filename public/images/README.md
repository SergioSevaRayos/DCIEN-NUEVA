# Directorio de Imágenes

## Estructura

- `/series/[slug]/` - Imágenes de cada serie
  - `main.jpg` - Imagen principal
  - `detail-1.jpg` - Detalle 1
  - `detail-2.jpg` - Detalle 2
  - etc.

- `og-image.jpg` - Imagen para Open Graph (1200x630px)
- `placeholder.jpg` - Imagen placeholder

## Formato Recomendado

- Formato: WebP o JPG optimizado
- Tamaño máximo: 500KB por imagen
- Dimensiones: 1200x1200px para imágenes de producto
- Usar lazy loading en todas las imágenes
