# SERIE 0 - Imágenes

## Coloca aquí tus imágenes:

- `main.jpg` - Imagen principal (1200x1200px mínimo)
- `detail-1.jpg` - Detalle 1
- `detail-2.jpg` - Detalle 2

## Especificaciones:
- Formato: JPG o PNG
- Tamaño: Cuadrado (1:1 ratio)
- Resolución: 1200x1200px o más
- Peso: < 500KB por imagen
- Fondo: Negro preferiblemente

Mientras no subas las imágenes reales, se mostrarán placeholders en desarrollo.
